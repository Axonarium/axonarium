## Goal

Sprint 0.3b gave every cited DOI a source record carrying its retraction status, but citations without a DOI had none, so a claim citing a retracted paper by its PubMed ID alone passed `cites-retracted`. This sprint gives every citation a source record and makes citations carry a DOI whenever one exists.

## Decisions

| Decision | Choice |
| --- | --- |
| Which record a citation needs | Its **source key**: `doi:<doi>` if it has a DOI, else `pubmed:<pmid>`, else `pmc:<pmcid>`, else `arxiv:<id without version>` |
| Citations that omit a known DOI | Online rule `citation-incomplete`: a citation must include the DOI its PubMed or PubMed Central record names, and the PubMed ID its PubMed Central record names. Modern papers therefore always use the DOI path, with Crossref's retraction data |
| Retraction status without a DOI | From PubMed: a record whose publication types include `Retracted Publication` is `retracted: true`. PubMed Central and arXiv records carry no retraction status, so their records omit `retracted` |
| Licences without a DOI | arXiv records take theirs from the preprint's DataCite DOI; PubMed and PubMed Central records have none, so their papers allow paraphrases only |
| arXiv withdrawals | Not covered: arXiv doesn't publish withdrawal status in a form the checks can read |

ADR 0007 is amended to match.

## Source records

`checks sources` writes a record for every source key a claim cites that has none, into `data/sources/<scheme>/`, named by the existing rule (`pubmed_1023575.yaml`). With `--refresh` it re-fetches every record of every scheme.

| Scheme | From | Fields |
| --- | --- | --- |
| `doi:` | Crossref or DataCite, as in sprint 0.3b | unchanged |
| `pubmed:` | NCBI esummary, `db=pubmed` | `title`; `year` (the first four digits of `pubdate`); `journal` (`fulljournalname`, else `source`); `retracted` (`true` if `pubtype` includes `Retracted Publication`, else `false`) |
| `pmc:` | NCBI esummary, `db=pmc` (the number without `PMC`) | `title`, `year`, `journal` as for PubMed |
| `arxiv:` | DataCite, for `10.48550/arXiv.<id>` | as for DataCite DOIs, with the `arxiv:` ID |

## Rules

| Rule ID | Change |
| --- | --- |
| `missing-source` | Now checks every claim's source key, not only DOIs |
| `cites-retracted`, `excerpt-licence` | Now read the record for the source key |
| `citation-incomplete` (new, online) | A citation without a DOI whose PubMed or PubMed Central record names one, or without a PubMed ID that its PubMed Central record names |
| `source-outdated` | Now compares records of every scheme with what `checks sources` would write today |
| `unknown-citation` | Also reported by `checks sources` for a PubMed, PubMed Central or arXiv ID that doesn't exist |

With `--base`, `checks online` adds the source records for the source keys of changed claims (it added only DOI records before).

## Schema

`Source.retracted`'s description becomes "Whether the paper has been retracted, per Crossref (for DOIs) or PubMed." Version 0.2.1; generated files regenerated.

## Tests

- **Offline:** `missing-source` for a claim citing a PubMed ID with no record; a claim citing a retracted paper by PubMed ID only (PMID 11134581, Mol Vis 2000, no DOI) with its record, `retracted: true`, gives `cites-retracted`; the existing excerpt test for a PubMed-only citation gains its record and still gives only `excerpt-licence`.
- **Builders:** from recorded responses, PMID 1023575 (1976, no DOI) gives `retracted: false`, PMID 11134581 gives `retracted: true`, PMC8129205 gives title, year and journal, and arXiv 2409.13740 gives `arxiv:2409.13740` with `CC-BY-SA-4.0`.
- **Online valid tree:** gains a claim citing PMID 1023575 only, with its record, and the arXiv record for the homology claim.
- **Online broken fixtures:** `citation-incomplete` (PMID 34001873 cited without the DOI PubMed names; PMC8129205 cited alone), and `source-outdated` gains a record for PMID 11134581 saying `retracted: false`.
- **`checks sources`:** writes the PubMed and arXiv records the online valid tree holds, byte for byte; reports `unknown-citation` for a PubMed ID that doesn't exist.
