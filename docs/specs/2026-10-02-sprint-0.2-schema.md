## Goal

One LinkML schema that encodes the data model in [docs/plan.md](../plan.md), Part 1. JSON Schema and PostgreSQL DDL are generated from it, and 20 example claims validate against it. Later sprints build on its interfaces: validation CI (0.3), the rebuild pipeline (0.4), the gold set (0.5) and the atlas layer (1.2).

## Decisions

| Decision | Choice |
| --- | --- |
| Example claims | Illustrative, not evidence: real atlas regions, species and evidence types, but every citation uses Crossref's test DOI prefix `10.5555`. They live in `schema/examples/`, never in `data/`. Real claims start with the gold set (0.5). |
| Identifier base | `https://w3id.org/axonarium/`. Registering the w3id redirect is a later, separate pull request to the w3id.org registry. |
| Claim and project IDs | A type prefix plus 10 random lowercase Crockford base32 characters (no i, l, o, u): `clm-` connectivity claims, `hom-` homology claims, `nt-` neuron types. No coordination between parallel agents; a collision is caught by sprint 0.3's uniqueness check. |
| Tooling | Plain LinkML in `schema/`. The LinkML copier template was rejected because it duplicates the existing scaffold and restores a Code of Conduct; a published Python package waits for sprint 3.4. |
| Versions | Python 3.13 (LinkML 1.11.1 declares support up to 3.13), LinkML 1.11.1, pinned in `uv.lock`. |
| Generated files | Committed, and checked to match the schema. |
| Region references | Either an atlas region ID, which then requires its pinned atlas version, or a UBERON term. UBERON covers species whose atlas is not pinned yet (sprint 1.2 pins rat and human). A claim always states its species, so regions in different species never merge. |

## Model

All slots use snake_case. IDs are CURIEs under the prefixes listed at the end of this section.

**Shared claim fields** (abstract class `Claim`):

| Slot | Range | Required | Notes |
| --- | --- | --- | --- |
| `id` | string | yes | Pattern per concrete class |
| `source` | `Citation` | yes | |
| `paraphrase` | string | yes | Copyright-safe summary of the evidence |
| `excerpt` | string | no | At most 300 characters; only from openly licensed papers (checked in 0.3) |
| `curation` | `Curation` | yes | |
| `verification` | `Verification` | no | |
| `status` | `ClaimStatus` | yes | |
| `extra` | Any | no | Map of namespaced keys (`lab.tracer`) to any JSON value. Key format enforced in 0.3 |

**`ConnectivityClaim`** (is a `Claim`, ID `^clm-[0-9a-hjkmnp-tv-z]{10}$`): `subject` and `object` (`EntityRef`, required), `predicate` (required), `species` (required), `evidence_class` (required), `result` (required), `sign` (required, so "unknown" is stated deliberately), `strength` (`OrdinalStrength`, optional), `measurements` (`Measurement`, multivalued, optional).

**`HomologyClaim`** (is a `Claim`, ID `^hom-[0-9a-hjkmnp-tv-z]{10}$`): `subject`, `subject_species`, `object`, `object_species`, `correspondence`, `confidence` (all required), and `basis` (`HomologyBasis`, multivalued, at least one).

**Value classes**, inlined into claims:

- `EntityRef`: `type` (`EntityType`), `id` (CURIE), `atlas` (atlas ID; required for atlas regions).
- `Citation`: `doi`, `pmid`, `pmcid`, `arxiv` (at least one), and `locator` (required, for example "Fig. 3B").
- `Curation` and `Verification`: `by` (`Actor`), `orcid`, `role` (`Role`), `model`, `prompt`, `date`. `Verification` adds `verdict` (required).
- `Measurement`: `quantity` (`QuantityKind`), `value` (float), `unit` (UCUM code), all required; `sd`, `sem`, `ci_low`, `ci_high` (floats) and `n` (integer, at least 1) optional. A missing value means unknown; nothing has a default.

**Entity classes**, one record per file in `data/entities/` from sprint 1.2 on:

- `Atlas`: `id` (slug such as `allen-mouse-ccf-2017`), `name`, `species`, `version`, `url`, `brainglobe_name`, `extra`.
- `Region`: `id` (atlas region CURIE), `name`, `acronym`, `atlas` (required), `parent`, `uberon`, `synonyms`, `extra`.
- `NeuronType`: `id` (`nt-` ID), `name`, `species`, `region` (`EntityRef`), `transmitter`, `markers` (gene symbols), `cell_ontology`, `synonyms`, `extra`.
- `Source`: `id` (`doi:`, `pubmed:`, `pmc:` or `arxiv:` CURIE), `title`, `year`, `journal`, `license`, `open_access`, `retracted`, `extra`.
- `KnowledgeBase` (tree root, for dumps): lists of each claim and entity class.

**Enums**:

| Enum | Values |
| --- | --- |
| `EntityType` | region, neuron_type |
| `ConnectivityPredicate` | projects_to, synapses_onto, functionally_connects_to |
| `EvidenceClass` | anterograde_tracer, retrograde_tracer, single_neuron_reconstruction, electron_microscopy, transsynaptic_tracer, optogenetic_circuit_mapping, paired_recording, electrical_stimulation |
| `Result` | present, absent, ambiguous |
| `Sign` | excitatory, inhibitory, modulatory, unknown |
| `OrdinalStrength` | weak, moderate, strong |
| `QuantityKind` | connection_probability, synapse_count, conduction_delay, projection_density, fraction_of_labelled_neurons |
| `ClaimStatus` | proposed, accepted, disputed, retracted |
| `Actor` | human, agent |
| `Role` | curator, ingester, extractor, verifier, reconciler, triage |
| `Verdict` | agree, disagree, unsure |
| `Correspondence` | equivalent, partial |
| `Confidence` | high, medium, low |
| `HomologyBasis` | connectivity, gene_expression, cytoarchitecture, development, function, expert_assertion |
| `Transmitter` | glutamate, gaba, acetylcholine, dopamine, serotonin, noradrenaline, neuropeptide, unknown |

**Rules**, enforced by the generated JSON Schema and therefore by `linkml-validate`:

1. Evidence classes never share a predicate: `projects_to` allows anterograde_tracer, retrograde_tracer and single_neuron_reconstruction; `synapses_onto` allows electron_microscopy and transsynaptic_tracer; `functionally_connects_to` allows optogenetic_circuit_mapping, paired_recording and electrical_stimulation.
2. An `EntityRef` of type region has an ID matching `^(MBA|HBA):\d+$` or `^UBERON:\d{7}$`; of type neuron_type, `^nt-[0-9a-hjkmnp-tv-z]{10}$` or `^CL:\d{7}$`.
3. An `MBA:` or `HBA:` ID requires `atlas`.
4. A human curator or verifier gives an `orcid`; an agent gives a `model` and a `prompt` (`^[a-z][a-z0-9_-]*@\d+\.\d+\.\d+$`, for example `extract@1.0.0`).
5. A `Citation` has at least one of `doi`, `pmid`, `pmcid` or `arxiv`.

**Patterns**: species `^NCBITaxon:\d+$`; atlas IDs `^[a-z0-9]+(-[a-z0-9]+)*$`; DOI `^10\.\d{4,9}/\S+$`; PMID `^\d+$`; PMCID `^PMC\d+$`; arXiv `^\d{4}\.\d{4,5}(v\d+)?$`; ORCID `^\d{4}-\d{4}-\d{4}-\d{3}[\dX]$`; UBERON `^UBERON:\d{7}$`; Cell Ontology `^CL:\d{7}$`.

**Prefixes**: `axonarium` (default) `https://w3id.org/axonarium/`; `NCBITaxon`, `UBERON`, `CL` (OBO PURLs); `MBA` and `HBA` (BICAN PURLs, as registered in the Bioregistry); `doi`, `pubmed`, `pmc`, `arxiv`, `orcid`.

## Examples

All in `schema/examples/valid/`. Regions use real Allen mouse CCF IDs (atlas `allen-mouse-ccf-2017`) or real UBERON terms; every UBERON ID is checked against the ontology before use. Citations use `10.5555/axonarium.example.NNN` DOIs; the human curator uses ORCID's test identity 0000-0002-1825-0097; paraphrases say they are illustrative.

- 15 `ConnectivityClaim` files covering: every predicate; every evidence class; every result (at least one absent and one ambiguous); every sign; `strength`; every quantity kind with a unit and at least one uncertainty field; at least one rat claim using UBERON regions; at least two neuron-type claims; `extra` keys; human curation, and agent curation with verification.
- 5 `HomologyClaim` files covering mouse–rat and mouse–human pairs, both correspondence values and all three confidence levels. One pairs mouse prelimbic cortex with human anterior cingulate cortex, the plan's translational example.
- Entity files for everything the claims reference: the atlas, at least two regions, the neuron types, and one source.

## Generation and checks

- `uv run gen-json-schema schema/axonarium.yaml > schema/generated/axonarium.schema.json`
- `uv run gen-sqltables --dialect postgresql --autogenerate_index false --generate_abstract_class_ddl false schema/axonarium.yaml > schema/generated/axonarium.sql`. Without these two flags the order of index statements depends on the schema file's path, so CI and contributors would regenerate different files; they also drop the empty table for the abstract `Claim` class.
- New `local` pre-commit hooks (`language: system`, so CI and laptops share one LinkML install through `uv`): `uv lock --check`, `linkml-lint` on the schema (errors fail), and the pytest suite. CI needs no workflow change: it already runs pre-commit with uv installed.

## Verification

1. `uv run pytest schema/tests` passes: at least 20 valid claim files validate, each invalid file fails with its expected message, and the generated files are current.
2. `uvx pre-commit run --all-files` passes, including the new hooks.
3. `linkml-lint` reports no errors.
4. CI passes on the pull request.
