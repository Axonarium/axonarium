## Goal

Every identifier a pull request adds or changes is looked up in the registry that owns it, so a hallucinated term, region or citation can't merge. Every cited DOI gets a `data/sources/` record holding its licence and retraction status, and the offline checks use those records to keep claims on retracted papers flagged and to allow verbatim excerpts only from openly licensed papers. This lands before agent extraction (sprint 2.3), whose main defence against invented citations it is.

## Decisions

| Decision | Choice |
| --- | --- |
| Lookup outages | Fail closed. A lookup that still fails after retries is a `lookup-failed` finding; the pull request can't merge until a re-run succeeds |
| Excerpt licences | CC BY (any version, including ported versions) and CC0 only. Share-alike, non-commercial and no-derivatives papers get paraphrases only, because project data is CC BY 4.0 ([ADR 0002](../decisions/0002-licensing.md)) |
| Citation identifiers | DOIs, PubMed IDs, PubMed Central IDs and arXiv IDs are all checked for existence, so a claim citing only a PubMed ID can't bypass the check. Source records are required for DOIs only |
| Periodic re-checks | Not in this sprint. The release job (sprint 3.2) runs the full check and refreshes source records |
| Registries | EBI OLS for UBERON, Cell Ontology and NCBITaxon; the Allen Brain Map API for MBA and HBA structures; doi.org for DOI existence; Crossref (including its Retraction Watch data) and DataCite for DOI metadata; NCBI E-utilities for PubMed and PubMed Central |
| Allen content | Looked up at check time and cached only in a git-ignored folder, never committed ([ADR 0005](../decisions/0005-source-reuse-terms.md)) |
| Dependencies | None new: the Python standard library's `urllib` |

Recorded in ADR 0007.

## Commands

- `uv run python -m checks online [--base <ref>] [--data data] [--cache .cache/checks]` looks up identifiers. With `--base`, only records in files added or changed since the merge-base of `<ref>` and `HEAD` (including uncommitted and untracked files), plus the source records those claims cite. Without it, every record.
- `uv run python -m checks sources [--refresh] [--data data] [--cache .cache/checks]` writes a source record for every DOI a claim cites that has none. With `--refresh`, it also re-fetches every existing DOI source record and rewrites those whose metadata changed, keeping `extra`. A DOI that doesn't exist is reported as `unknown-citation` and nothing is written for it.

Both print findings as `<path>: <rule-id>: <message>` and exit with status 1 if there are any; `sources` also prints each file it writes.

## What is looked up

Identifiers are collected from every string value outside `extra` that is exactly a CURIE with one of these prefixes, and from each claim's `source` citation and each source record's `id`. Only identifiers in canonical form are looked up: ASCII digits, nothing around them, no leading zero in PubMed and PubMed Central IDs, and DOIs of printable ASCII. Any other form is `unknown-term` or `unknown-citation` without a lookup, and `checks sources` writes no record for it. A registry answer of an unexpected shape is `lookup-failed`.

| Identifier | Registry and request | Exists when | Obsolete when |
| --- | --- | --- | --- |
| `UBERON:`, `CL:`, `NCBITaxon:` | OLS: `https://www.ebi.ac.uk/ols4/api/ontologies/<uberon\|cl\|ncbitaxon>/terms?obo_id=<curie>` | 200 with a term | the term's `is_obsolete` is true (the message names `term_replaced_by` if set) |
| `MBA:<n>`, `HBA:<n>` | Allen: `https://api.brain-map.org/api/v2/data/Structure/query.json?criteria=[id$eq<n>]` | a structure with that ID in graph 1 (MBA) or graph 10 (HBA) | not applicable |
| DOI (`source.doi`, `doi:` source IDs) | doi.org: `https://doi.org/ra/<doi>` | an entry with an `RA` (registration agency) | not applicable |
| PubMed ID (`source.pmid`, `pubmed:` source IDs) | `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id=<n>&retmode=json` | the result for the ID has no `error` | not applicable |
| PubMed Central ID (`source.pmcid`, `pmc:` source IDs) | the same with `db=pmc` and the number without `PMC` | likewise | not applicable |
| arXiv ID (`source.arxiv`, `arxiv:` source IDs) | its DataCite DOI, `10.48550/arXiv.<id without version>`, at doi.org | as for DOIs | not applicable |

## Source records

**File name:** the ID with the scheme's `:` written as `_`, `/` written as `_`, letters, digits and `.()-` kept, and every other character percent-encoded as UTF-8 bytes (`%XX`, upper-case hex), plus `.yaml`. So `doi:10.1038/s41467-021-22915-5` is `doi_10.1038_s41467-021-22915-5.yaml`, and an underscore in a DOI becomes `%5F`. Any folder under `data/sources/` is allowed; `checks sources` writes to `data/sources/<scheme>/`.

**Fields** (`checks sources` writes them in this order, omitting any it can't fill):

| Field | From Crossref (`https://api.crossref.org/works/<doi>`) | From DataCite (`https://api.datacite.org/dois/<doi>`) |
| --- | --- | --- |
| `id` | `doi:` plus the DOI as cited (lowercase) | likewise |
| `title` | `title[0]`, with markup tags removed and whitespace collapsed | `titles[0].title`, likewise |
| `year` | `issued.date-parts[0][0]` | `publicationYear` |
| `journal` | `container-title[0]` | `container.title`, else the publisher's name |
| `license` | the licence entry whose `content-version` is `vor` or `unspecified` and whose start date is given and has passed: its SPDX ID if it is a Creative Commons URL, else its URL; a Creative Commons entry wins over others | the first `rightsList` entry: its SPDX ID (Creative Commons IDs in SPDX case), else its Creative Commons URL's SPDX ID |
| `open_access` | `true` when `license` is a Creative Commons licence; omitted otherwise | likewise |
| `retracted` | `true` if any `updated-by` entry has type `retraction`, `withdrawal` or `removal`; otherwise `false` | omitted (DataCite has no retraction data) |

DOIs registered with other agencies get a record with `id` only. Abstracts are never stored ([ADR 0005](../decisions/0005-source-reuse-terms.md)).

**Creative Commons URLs to SPDX:** `creativecommons.org/licenses/<by[-nc][-nd][-sa]>/<version>[/<jurisdiction>]` (http or https, optional `www.`, trailing slash, `legalcode` or `deed.*`) gives `CC-<CODE>-<version>[-<JURISDICTION>]` in upper case; `creativecommons.org/publicdomain/zero/1.0` gives `CC0-1.0`.

**Open licences:** `CC0-1.0`, and `CC-BY-<version>` with an optional jurisdiction suffix (no `-SA`, `-NC` or `-ND`).

## Rules

**Offline, added to `checks files`** (cross-file):

| Rule ID | Check |
| --- | --- |
| `file-name` | Extended to source records, with the name rule above |
| `missing-source` | Every DOI a claim cites has a source record with ID `doi:<doi>` |
| `cites-retracted` | A claim whose cited DOI's source record has `retracted: true` has status `retracted` |
| `excerpt-licence` | A claim with an `excerpt` cites a DOI whose source record's `license` is open |

**Online, in `checks online`:**

| Rule ID | Check |
| --- | --- |
| `unknown-term` | Every ontology term exists, and every MBA or HBA ID is a structure in its atlas's graph |
| `obsolete-term` | No ontology term is obsolete |
| `unknown-citation` | Every DOI, PubMed ID, PubMed Central ID and arXiv ID exists |
| `citation-mismatch` | A claim's PubMed and PubMed Central records name the same DOI as its `source.doi`, and its PubMed Central record names the same PubMed ID as its `source.pmid` |
| `source-outdated` | A DOI source record's `license` and `retracted` equal what `checks sources` would write today; the fix is `checks sources --refresh` |
| `lookup-failed` | A lookup still failed after retries, or a registry answered unexpectedly |

A newly retracted paper therefore fails as `source-outdated` until its record is refreshed, then as `cites-retracted` until each claim citing it is retracted, which needs a `retracted` log entry and so the maintainer's review (ADR 0006).

## Network behaviour

- **Requests:** HTTPS GET with JSON accepted, a 30-second timeout and the User-Agent `axonarium-checks (https://github.com/axonarium/axonarium; mailto:admin@axonarium.com)`, which Crossref's polite pool asks for. NCBI requests also carry `tool=axonarium-checks` and `email=admin@axonarium.com`.
- **Rate limits:** at least 0.4 seconds between requests to NCBI (its limit without a key is three a second) and 0.15 seconds between requests to any other host.
- **Retries:** up to 4 attempts on HTTP 429 or 5xx, timeouts and connection errors, waiting 1, 2 and 4 seconds, or the `Retry-After` header's seconds (at most 30). 404 and 410 mean "not found". Any other status, a URL the client refuses, or a body that isn't the expected JSON, is a lookup failure without retries.
- **Outages:** once a host fails every attempt for one URL, later requests to that host in the same run fail at once, so an outage costs one URL's retries rather than every identifier's. A failed URL isn't asked twice in a run.
- **Cache:** successful (200) responses are stored as JSON under the cache folder, keyed by the SHA-256 of the URL, for 7 days; an entry dated in the future is ignored. Failures and 404s are never cached. The folder (`.cache/` by default) is git-ignored. `checks sources --refresh` ignores cached answers and stores new ones. In CI the cache is under `$RUNNER_TEMP`, outside the checkout, so it starts empty and a pull request can't plant answers.
- **Each identifier is looked up once per run**, however many records use it.

## Wiring

- **CI:** in `.github/workflows/ci.yml`, the `checks` job runs `checks online --base "origin/$BASE_REF"` on pull requests, after the change gate. The job is the required status, so the check can't be bypassed. A pull request that changes nothing under `data/` makes no requests.
- **Pre-commit:** unchanged apart from the new offline rules, which run in the existing `data-checks` hook; the online check needs the network and runs in CI.
- `.gitignore` gains `.cache/`.

## Tests

- **No network in the test suite.** Registry responses are recorded from the real services, trimmed to the fields the checks read, and replayed by a fake opener that fails the test on any URL it has no recording for. Setting `AXONARIUM_RECORD=1` re-records through the real network.
- **Offline valid tree:** the schema examples gain a source record for each of the 20 example DOIs, and one example claim gains an excerpt from an openly licensed example source. The tree must still produce no findings.
- **Offline broken fixtures:** `missing-source`, `cites-retracted` and `excerpt-licence`, each failing with exactly its own rule, as in sprint 0.3.
- **Online valid tree:** a small tree, `checks/tests/fixtures/online/valid/`, of real identifiers: a mouse claim on Hintiryan et al. 2021 (`10.1038/s41467-021-22915-5`, CC BY 4.0) with its PubMed and PubMed Central IDs, a homology claim from the mouse central amygdalar nucleus (MBA) to its human UBERON term, citing an arXiv ID, an atlas, a neuron type with a Cell Ontology term, and the source record. It must produce no findings online or offline.
- **Online broken fixtures:** overlays in `checks/tests/fixtures/online/broken/<rule-id>/` for `unknown-term` (an unknown UBERON term and an MBA ID that isn't a structure), `obsolete-term`, `unknown-citation` (a DOI that doesn't exist and an arXiv ID that doesn't exist), `citation-mismatch` (a PubMed ID for a different paper), and `source-outdated` (a record for Wakefield et al. 1998, `10.1016/s0140-6736(97)11096-0`, claiming it isn't retracted). `lookup-failed` is tested by making the fake opener fail.
- **Units:** the file-name rule, Creative Commons URL parsing, the open-licence test, building records from recorded Crossref and DataCite responses, and the fetcher's cache, rate limit and retries (with injected clock and sleep).
- **Scope:** in a temporary git repository, `online --base` looks up only identifiers in changed files plus the source records their claims cite, and makes no requests when nothing under `data/` changed.
