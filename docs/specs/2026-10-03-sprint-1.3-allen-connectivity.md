## Goal

The first real connections on the site: region-level projections from the amygdala, from the Allen Mouse Brain Connectivity Atlas (Oh et al. 2014, DOI 10.1038/nature13186).

## What the data offers (checked 3 October 2026)

75 experiments have their primary injection in a mouse amygdala region or one of its subdivisions (the 11 amygdala regions of sprint 1.2 and their 23 structures). 22 are wild-type (BMA 5, MEA 5, COAp 4, BLA 3, CEA 3, AAA 1, TR 1); 53 use Cre lines, which label cell types and belong with neuron-type claims later. Each experiment reports projection density for every Allen structure (`ProjectionStructureUnionize`, both hemispheres together).

## Decisions

| Decision | Choice |
| --- | --- |
| Licence | Allen terms: claims are made at build time, never committed, never in the dumps; the live, non-commercial site shows them with the citation (ADR 0005) |
| Access | The Allen Brain Map REST API through `requests` with urllib3 `Retry`. AllenSDK, the dedicated package, can't install on Python 3.13 (it pins numpy < 1.24 and pandas 1.5.3) |
| Experiments | Wild-type (no transgenic line) Mouse Connectivity Projection experiments (product 5) that didn't fail QC, with the primary injection in an amygdala region or its subdivisions |
| Targets | Allen's 316 summary structures (structure set 167587189), the set its own analyses use, excluding the injection structure itself |
| Claims | One per experiment and target with projection density ≥ 0.01: `projects_to`, anterograde tracer, result present, sign unknown, a `projection_density` measurement (unit 1), citing Oh et al. 2014 with the experiment as the locator, curated by an agent with role `ingester` and the adapter as its model, status accepted. Absent results (density below the threshold) wait for a decision on detection limits |
| IDs | `clm-` plus 10 Crockford base32 characters of a SHA-256 of the experiment and target, so a rerun gives the same claims |
| Checks | Generated claims pass the same per-file and cross-file rules as committed ones before they reach the database; the build stops otherwise |
