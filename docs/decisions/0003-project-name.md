# Project name: Axonarium

## Context and Problem Statement

The project's working name was "Circuit Commons". It needed a name that is easy to say and remember, fits a map of the brain and body, and has both the .com and .org domains free. Which name should it use?

## Considered Options

* Axonarium
* Synaptarium
* Wiringbook
* PlexAtlas
* PlexusAtlas
* Tractlas

## Decision Outcome

Chosen option: "Axonarium", because:

* it is a place to explore, like a planetarium or an aquarium, which suits the 3D explorer;
* axons are the connections the project maps, including peripheral nerves, so the name covers the brain and the body;
* it pitches well: "Axonarium: an open, cited map of how the brain and body are wired."

The others lost for these reasons (plan Part 3.1):

* Synaptarium: longer and harder to say.
* Wiringbook: broad and plain.
* PlexAtlas: Plexon, a neuroscience hardware company, uses "Plex" across its products.
* PlexusAtlas: Plexus Worldwide sells gut-health supplements, an awkward neighbour for a resource that will carry gut–brain claims.
* Tractlas: implies diffusion tractography, only one kind of evidence.

axonarium.com and axonarium.org were registered at GoDaddy on 2 October 2026, and organizations named axonarium were created on GitHub, npm and PyPI.

### Consequences

* Good, because the name, both domains and the package namespaces are held together.
* Bad, because a trademark search is still needed before announcing.
* Bad, because the PyPI project name `axonarium` is still unclaimed; a PyPI organization does not reserve it.
