# Sprint 1.2: Atlas layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pin three atlases, load their hierarchies at build time with BrainGlobe, map regions to UBERON from UBERON's bridges, refuse unknown regions, and show region names on the site.

**Architecture:** `ingest/atlases.py` (the plan's adapter folder) turns BrainGlobe structures and UBERON bridge OWL into region rows; `build` merges them into the `regions` table and checks data references; the site reads `regions`.

**Tech Stack:** brainglobe-atlasapi 3.0.2, rdflib (already present through LinkML), SQLAlchemy/Alembic (no schema change to tables), Next.js.

**Spec:** [docs/specs/2026-10-03-sprint-1.2-atlas-layer.md](../specs/2026-10-03-sprint-1.2-atlas-layer.md)

## Review Focus

1. **BrainGlobe serves a newer atlas version** than the pin: the build stops with a message naming both versions. Task 2 `test_pin_mismatch_stops`.
2. **A bridge class whose intersection starts with another intersection** (layer-specific terms) maps to nothing rather than to the wrong UBERON term. Task 2 `test_nested_intersection_not_exact`.
3. **A claim naming `MBA:` with the human atlas** (or an ID absent from its atlas) stops the build. Task 3 `test_unknown_region_stops_build`.
4. **Offline builds** (`--no-atlases`) still work and don't report unknown regions they can't check. Task 3.
5. **Allen names never reach the dumps.** Task 3 `test_atlas_regions_not_in_dumps`.
