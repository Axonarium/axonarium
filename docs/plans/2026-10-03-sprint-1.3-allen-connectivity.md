# Sprint 1.3: Allen mouse connectivity adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Region-level `projects_to` claims from wild-type amygdala injections in the Allen Mouse Brain Connectivity Atlas, made at build time, checked like committed claims, idempotent.

**Architecture:** `ingest/allen_connectivity.py` queries the Allen API (requests + urllib3 Retry) and builds claim dicts with pure functions; the build validates them with the checks' rules and adds them to the database rows (not the dumps).

**Spec:** [docs/specs/2026-10-03-sprint-1.3-allen-connectivity.md](../specs/2026-10-03-sprint-1.3-allen-connectivity.md)

## Review Focus

1. **A rerun gives identical claims** (IDs, order, values). `test_rerun_is_identical`.
2. **Generated claims pass schema validation and every rule**, or the build stops. `test_claims_pass_the_checks`.
3. **Cre-line and failed experiments are excluded.** `test_wild_type_only`.
4. **The injection structure isn't its own target; densities below 0.01 make no claim.** `test_targets`.
5. **Allen-derived claims never reach the dumps.** `test_allen_claims_not_in_dumps`.
