> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the empty public repo axonarium/axonarium into a governed scaffold: licences, community and agent docs, sprint cards, ownership rules, branch protection, and CI that passes on a repo with no code.

## Review Focus

1. **Status check name mismatch.** If the ruleset requires a check name that CI never reports, every pull request is blocked. Task 9 Step 4 asserts that `main`'s check runs include `checks` from GitHub Actions (app id 15368) before the ruleset exists.
2. **Broken CODEOWNERS.** An unknown owner or bad syntax silently turns off code-owner review. Task 8 Step 3 asserts that GitHub reports no CODEOWNERS errors.
3. **Bypass mode.** `always` instead of `pull_request` would let an admin push straight to `main` and skip CI. Task 9 Step 6 asserts `pull_request`.
4. **Default labels deleted by the sync.** Task 10 Step 1 asserts that `bug` and `good first issue` survive.
5. **Private content leaking.** Task 5 Step 1 greps docs/plan.md for Part 4 and 5 references, the private doc link and personal background. Task 8 Step 1 asserts that axonarium-project-plan.md is in no commit.
