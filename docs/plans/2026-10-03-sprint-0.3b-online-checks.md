# Sprint 0.3b: Online identifier and citation checks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Look up every identifier a pull request adds in the registry that owns it, keep a source record with licence and retraction status for every cited DOI, and use those records offline to flag claims on retracted papers and to limit excerpts to openly licensed ones.

**Architecture:** Pure helpers (`checks/identifiers.py`) name source files and read licences. A `Fetcher` (`checks/http.py`) does polite, cached, retried HTTPS GETs through an injectable opener. `checks/lookups.py` asks each registry one question. `checks/sources.py` builds and writes source records; `checks/online_rules.py` turns lookups into findings. Two new commands, `online` and `sources`, join `files` and `changes`; CI runs `online --base` on pull requests.

**Tech Stack:** Python 3.13 standard library (`urllib`, `hashlib`, `json`), PyYAML, pytest, git. No new dependencies.

**Spec:** [docs/specs/2026-10-03-sprint-0.3b-online-checks.md](../specs/2026-10-03-sprint-0.3b-online-checks.md)

## Global Constraints

- Branch `sprint/0.3b-online-checks`; commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; never stage axonarium-project-plan.md.
- "Run the tests": `uv run --frozen pytest -q schema/tests checks/tests`. "Run the checks": stage, then `uvx pre-commit@4.6.2 run --all-files`.
- The test suite never touches the network: every HTTP request in a test goes through the replay opener (Task 3), which fails the test on an unrecorded URL.
- Rule IDs, the file-name rule, the registry URLs, the field mapping, the open-licence set, the rate limits, retries and cache TTL are exactly as in the spec.
- User-Agent: `axonarium-checks (https://github.com/axonarium/axonarium; mailto:admin@axonarium.com)`.
- Findings print as `<path>: <rule-id>: <message>`, sorted; any finding means exit status 1.

## Review Focus

1. **DOIs with characters that need escaping** (`<`, `>`, `;`, `#`, `(`, `_`): request URLs must percent-encode the DOI, and file names must follow the escape rule. Task 1 `test_source_file_name` covers a SICI DOI; Task 3 `test_doi_is_quoted_in_requests` checks the URL sent.
2. **Mixed-case DOIs from PubMed** (`10.1038/S41467-...`) against a lowercase citation must not be a mismatch. Task 4 `test_pubmed_doi_case_ignored`.
3. **Embargoed licences** (a Creative Commons start date in the future) don't count yet. Task 3 `test_crossref_licence_not_yet_started`.
4. **An excerpt on a claim that cites only a PubMed ID** has no source record and so no licence: `excerpt-licence`. Task 1 `test_excerpt_without_doi`.
5. **A `Retry-After` larger than the 30-second cap** must not stall CI. Task 2 `test_retry_after_capped`.
